# C-Car-Obstacle-Game

# C++ Car Obstacle Game

A simple console-based car obstacle game built in C++.

# Features
- Player movement using A and D keys
- Random obstacle generation
- Collision detection
- Score tracking
- Game over condition
- Organized using a C++ class

# Concepts Used
- Classes and objects
- Functions
- Loops
- If statements
- Random numbers
- User input
